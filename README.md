# Machine Learning Practice 2

## 📌 Project Overview
This project focuses on practicing Machine Learning concepts using Python. It covers data preprocessing, Logistic Regression, model training, prediction, and performance evaluation.

## 🎯 Objectives
- Understand the fundamentals of Machine Learning.
- Perform data preprocessing and exploratory data analysis.
- Implement Univariate and Multivariate Logistic Regression.
- Train a machine learning model and make predictions.
- Evaluate model performance using suitable metrics and visualizations.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Machine-Learning-Practice-2
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib scikit-learn jupyter
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the notebook and run the cells step by step.

## 📊 Project Workflow

1. Import the required Python libraries.
2. Load the dataset.
3. Explore and preprocess the data.
4. Prepare the independent and dependent variables.
5. Implement Logistic Regression.
6. Train the model and generate predictions.
7. Evaluate the model and visualize the results.
